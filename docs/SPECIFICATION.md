# 規格說明書 (Specification)

專題名稱：**商店庫存管理系統 (Store Inventory Management System)**
學號：4B4G0039　　開發語言：C++ (C++14)

---

## 1. 系統目標

提供一套在終端機操作的商店庫存管理工具，協助店家管理三大類商品
（食品、電子產品、服飾）的庫存數量、價格與類別專屬資訊，並具備
資料永久保存（檔案讀寫）能力。

---

## 2. 功能需求 (Functional Requirements)

| 編號 | 功能 | 說明 |
|------|------|------|
| F1 | 新增商品 | 選擇類別後輸入名稱、單價、數量與類別專屬欄位，系統自動配發編號 |
| F2 | 顯示所有商品 | 列出全部商品，依實際類別顯示不同格式（多型） |
| F3 | 依類別顯示 | 只列出食品 / 電子 / 服飾其中一類 |
| F4 | 搜尋商品 | 依名稱關鍵字做模糊比對 |
| F5 | 進貨 | 對指定編號增加庫存 |
| F6 | 銷售 | 對指定編號減少庫存；庫存不足則拒絕 |
| F7 | 修改價格 | 變更指定商品單價 |
| F8 | 刪除商品 | 移除指定編號商品 |
| F9 | 統計報表 | 以類別統計種類數與庫存總值 |
| F10 | 儲存至檔案 | 將目前庫存寫入 `data/inventory.txt` |
| F11 | 從檔案讀取 | 重新由檔案載入庫存 |
| F12 | 離開系統 | 自動存檔後結束 |

---

## 3. 非功能需求 (Non-Functional Requirements)

- **正確性**：銷售時若數量大於庫存則操作失敗，不可出現負庫存。
- **健壯性**：對非數字輸入需有錯誤處理，避免程式崩潰。
- **永續性**：資料以純文字檔保存，跨次執行不遺失。
- **可維護性**：採物件導向設計，新增商品類別時只需新增一個衍生類別。

---

## 4. 資料結構設計

### 4.1 類別繼承

| 類別 | 角色 | 專屬屬性 |
|------|------|----------|
| `Product` | 抽象基底類別 | id、name、price、quantity |
| `Food` | 衍生類別 | expiry（有效期限） |
| `Electronics` | 衍生類別 | warranty（保固月數） |
| `Clothing` | 衍生類別 | size（尺寸） |

虛擬函式：`category()`、`displayDetail()`、`serialize()`（皆為純虛擬，由衍生類別實作）。

### 4.2 STL 容器使用

| STL | 使用位置 | 用途 |
|-----|----------|------|
| `std::vector<std::unique_ptr<Product>>` | `Inventory::products_` | 儲存所有商品（多型 + 自動記憶體管理） |
| `std::map` | `Inventory::displayReport()` | 統計各類別數量與金額 |
| `std::string` | 全系統 | 文字處理 |
| `std::stringstream` | `loadFromFile()` | 解析檔案欄位 |
| `std::remove_if` (`<algorithm>`) | `removeById()` | 刪除商品 |

---

## 5. 檔案格式 (data/inventory.txt)

每行一筆，欄位以 `|` 分隔，第一欄為類別關鍵字：

```
Food|1001|蘋果|18.000000|120|2026-07-30
Electronics|1003|藍牙耳機|1290.000000|25|12
Clothing|1005|純棉T恤|350.000000|80|M
```

| 欄位順序 | Food | Electronics | Clothing |
|---------|------|-------------|----------|
| 1 | 類別 = Food | Electronics | Clothing |
| 2 | 編號 | 編號 | 編號 |
| 3 | 名稱 | 名稱 | 名稱 |
| 4 | 單價 | 單價 | 單價 |
| 5 | 數量 | 數量 | 數量 |
| 6 | 有效期限 | 保固月數 | 尺寸 |

讀檔時依第 1 欄決定要建立哪一種衍生物件（工廠模式）。

---

## 6. 例外與邊界條件

| 情境 | 系統反應 |
|------|----------|
| 輸入非數字 | 顯示「輸入錯誤」並要求重新輸入 |
| 銷售數量 > 庫存 | 操作失敗，庫存不變 |
| 查無編號 | 顯示「找不到該商品」 |
| 資料檔不存在 | 以空白庫存啟動 |
